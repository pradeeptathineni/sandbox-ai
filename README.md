# Sandbox AI

Reusable methods for safe trials, evidence organization, metrics, review and scoped adoption recommendations.

Start with the [trial template](templates/trial.md), [evidence meanings](docs/evidence.md) and [evidence index](evidence/index.json). The [synthetic example](examples/synthetic-trial.md) demonstrates a failed attempt and an unresolved choice. It reports no real tool or model result.

Sandbox can evaluate tools, models, contexts and projects, including the systems that supply its own candidates and guidance. Its evidence can inform reusable Context equipment, private Custom choices or project-local decisions. Recommendations remain advisory.

This repository contains documents and fixtures. Trial execution and isolation belong to the authorized native host or an existing reviewed recipe. It supplies no installer, runner, agent configuration, model calls, hooks or service. See [Context reuse](docs/context-reuse.md) for the existing contracts.

The [Watchexec polling report](evidence/watchexec-polling/report.md) records real bounded execution on synthetic inputs, including failures, resource limits and an advisory fast-check recommendation. It does not record production adoption.

The [Agent-Reach public trial](evidence/agent-reach-1.5.0-public-trial.md) records exact-source setup, paired web reads, same-byte RSS parsing and blocked upstream access. It recommends reusing current transports, not an additional adapter or broader evidence authority.

Keep personal locations, original private receipts and migration maps with their private owner. Public entries require a separate content/provenance review. Repository checks establish structure, never usefulness. [Repository guidance](AGENTS.md) describes maintenance.
